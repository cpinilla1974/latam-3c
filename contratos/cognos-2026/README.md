# Contrato FICEM-Cognos 2026

## Descripción

Desarrollo de dos módulos de inteligencia artificial para FICEM:

1. **FICEM Watch** - Vigilancia comunicacional en tiempo real
2. **FICEM Analytics** - Reportabilidad inteligente con agentes de análisis

## Proyectos

### 1. [FICEM Watch](../../proyectos/ficem-cognos/ficem-watch/)
Monitoreo de posición comunicacional de FICEM frente al acontecer global y objetivos estratégicos.

### 2. [FICEM Analytics](../../proyectos/ficem-cognos/ficem-analytics/)
Agentes IA para análisis, depuración y rastreo de datos de reportabilidad.
