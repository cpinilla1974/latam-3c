## FASE 1: Estrategia Comunicacional

### Objetivo
Construir la estrategia de comunicaciones de FICEM a partir del analisis de toda la documentacion disponible.

### 1.1 Acopio de Documentos

| Tipo de documento | Valor para el plan |
|-------------------|-------------------|
| Actas de reunion FICEM | Posiciones internas, debates, consensos |
| Reportes sostenibilidad empresas | Posiciones publicas de miembros |
| Documentos GCCA | Marco del partner global |
| NDCs paises | Contexto regulatorio por pais |
| Planes comunicacion (referencia) | Benchmarking de estructura |

**Nota**: La cantidad exacta de documentos a procesar se definira una vez establecidas las herramientas y metodos de analisis.

### 1.2 Procesamiento con IA

Para cada documento extraemos:
- **Temas mencionados** (descarbonizacion, coprocesamiento, economia circular, etc.)
- **Posiciones expresadas** (a favor, en contra, matices, condiciones)
- **Actores mencionados** (gobiernos, GCCA, competidores, reguladores)
- **Tono** (tecnico, politico, defensivo, propositivo)

### 1.3 Marco de Analisis

Al procesar los documentos, buscamos identificar:

| Pregunta estrategica | Que buscamos en los documentos |
|---------------------|-------------------------------|
| ¿Para que comunica FICEM? | Objetivos ya definidos, mision, vision comunicacional |
| ¿Sobre que temas? | Temas recurrentes, prioridades, agendas |
| ¿A quienes? | Audiencias mencionadas, stakeholders, actores clave |
| ¿Con que posiciones? | Argumentos usados, mensajes existentes, narrativas |
| ¿Con que restricciones? | Temas sensibles, limites, validaciones necesarias |

Este marco es **para nosotros** como guia de analisis. No es un cuestionario para FICEM.

### 1.4 Entregable Fase 1

**Mapa de Posiciones de FICEM** que incluye:

1. **Documento**: Estrategia comunicacional estructurada
2. **Base de datos consultable**: Integrada en FICEM Watch

El software permite:
- Consultar posiciones por tema
- Filtrar por actor/fuente
- Ver contexto (pais, fecha, tipo de documento)
- Explotar la estrategia para generar contenidos

## FASE 2: Estructura del Plan

### 2.1 Componentes del Plan

```
1. Proposito comunicacional
   - ¿Para que comunica FICEM?
   - Alineacion con los 3 pilares

2. Mapa de publicos
   - Quienes son (gobiernos, empresas, medios, academia, etc.)
   - Que necesitan de FICEM
   - Como prefieren recibir informacion

3. Ejes narrativos (estables)
   - 3-5 ideas fuerza que no cambian con el contexto politico
   - Ejemplo: "Descarbonizacion como proceso tecnico gradual"

4. Mensajes por publico
   - Mismo eje, distinto lenguaje
   - Version tecnica / politica / mediatica

5. Clasificacion de temas
   - Proactivos: Comunicar siempre (sostenibilidad, innovacion)
   - Monitoreo: Observar y preparar (cambios legislativos)
   - Sensibles: Validar antes de hablar (conflictos, crisis)

6. Gobernanza
   - Quien puede hablar (voceria)
   - Sobre que temas
   - Con que validacion previa

7. Mecanismo de actualizacion
   - Cada cuanto se revisa
   - Que dispara una revision (cambio de gobierno, crisis, etc.)
```

### 2.2 Horizontes de Revision

- **Semanal**: Que comunicamos esta semana
- **Trimestral**: Eventos proximos, ajustes tacticos
- **Anual**: Revision de ejes narrativos

## FASE 3: Iteracion Continua

### 3.1 Mecanismo de Feedback

El plan vive dentro de FICEM Watch:

```
Maria Jose usa el sistema (Telegram/Web)
    ↓
Corrige/ajusta respuestas del asistente
    ↓
Sistema aprende el "tono Maria Jose"
    ↓
Plan se refina continuamente
```

### 3.2 Actualizacion Dinamica

El plan no es un PDF que se archiva. Es un componente del software que:
- Se consulta para generar contenidos
- Se actualiza cuando cambia el contexto
- Aprende del uso real
