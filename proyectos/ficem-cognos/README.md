# FICEM-Cognos - Módulos de Inteligencia Artificial

## Visión General

Dos proyectos de IA para FICEM:

### 1. [FICEM Watch](ficem-watch/) - Vigilante Comunicacional
Monitoreo en tiempo real de posición comunicacional de FICEM frente al acontecer global y objetivos estratégicos.

### 2. [FICEM Analytics](ficem-analytics/) - Reportabilidad Inteligente
Agentes IA para análisis, depuración y rastreo de datos de reportabilidad.

## Fuentes de Datos

**Documentos** (~180):
- Redes Sociales
- 30 Reportes de Sostenibilidad
- 41 Buenas Prácticas FICEM
- 5 Congresos FICEM
- ~100 Docs internos FICEM

**Organizaciones**: GCCA, FIP, IEA, CMBUREAU, BID, IFC, CAF, ONU

**Gobiernos**: Perú (CNCND, OICHA)

## Estado

Ambos proyectos en fase de **conceptualización**.
